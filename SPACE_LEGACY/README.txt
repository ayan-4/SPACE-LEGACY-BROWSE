SPACE LEGACY — Homepage starter

WINDOWS SETUP
1. Extract this ZIP.
2. Open the SPACE_LEGACY folder in Visual Studio Code.
3. Open index.html.
4. Recommended: install the "Live Server" extension in VS Code.
5. Right-click index.html and select "Open with Live Server".
6. Or double-click index.html to open it in Chrome or Edge.

FILES
- index.html: homepage structure and text
- style.css: responsive styling, starfield and CSS planet illustrations
- script.js: mobile navigation and active navigation state
- assets/images/: reserved for NASA images you add later

NOTES
The planet and artifact visuals in this first homepage are CSS illustrations, not actual photographs of spacecraft. Add authentic NASA images to the detailed artifact pages and include source/credit information. Mission cards link to NASA mission records. This is an independent student project, not an official NASA website.
